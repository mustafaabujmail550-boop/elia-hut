# منيو كوخ إيليياء

موقع منيو ثابت (HTML + CSS + JS) بدون أي أدوات بناء.

## الملفات
- `index.html` الصفحة الرئيسية
- `css/style.css` التصميم والألوان (المتغيرات في أول الملف)
- `js/menu.js` الأصناف والأسعار (عدّل الأسعار والأصناف من هون)
- `images/` الشعار ورسومات الأكلات

## النشر على GitHub Pages
1. ارفع كل محتويات المجلد إلى مستودع جديد (يكون `index.html` في الجذر).
2. من Settings ثم Pages اختر Branch: main و Folder: / (root) واضغط Save.
3. بعد دقيقة بيظهر الرابط: `https://USERNAME.github.io/REPO/`

ملاحظة: الخطوط من Google Fonts فبدها إنترنت.
